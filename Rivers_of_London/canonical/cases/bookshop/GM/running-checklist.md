# The Bookshop - Running Checklist

## Before Play

- Confirm player access to `input/player.md`.
- Confirm GM can see this folder and the player cannot.
- Decide whether to use pregens or practice investigators.
- Encourage one magical investigator with Werelight if possible.
- Open the player and GM maps in Edit Files to check artifact visibility.

## During Play

- Give Warwick handout after credentials are shown.
- Give Saffron handout when she explains what she found.
- Give research note when cockfighting/dome research lands.
- Track whether CCTV still works.
- Track whether Werelight was cast.
- Track whether Ernie is present.
- Track who, if anyone, is Hurt/Bloodied/Down after the book barrage.

## After Play

- Run development phase.
- Regenerate Player Scenario Info from the short `player.md` plus revealed handouts.
- Regenerate GM Analysis from the GM files.
- Try GM Chat questions against the case secrets.
- Edit one seeded file locally, then use Reset from the Case Files card to restore canonical content.
