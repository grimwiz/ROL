# Rules

This folder contains the mechanically complete, paraphrased rules reference as it is drafted.

Files marked `extracted-draft` in their source comments have not yet had final completeness review. Use `../tracking/source-map.md` to choose the next section and update its status as work proceeds.

Expected top-level files will likely cover:

- Character creation and advancement.
- Skills and core d100 procedures.
- Luck, opposed rolls, impairment, and development.
- Combat, damage, healing, chases, and vehicles.
- Newtonian magic, spellcasting, vestigia, signare, and spell lists.
- Demi-monde mechanics and optional rules.
