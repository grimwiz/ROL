This inventory describes the current raw seed generated by `npm run extract:source`. It is a planning aid for LLM-assisted distillation and should not be treated as final extracted content. Completion still requires the PDF gate tracked in `pdf-review.md`.

## Raw Seed

Generated files live under `private/extracted-source/` and are gitignored:

- `rulebook-relevant.md` - combined source seed.
- `manifest.json` - source line ranges, word counts, destination hints.
- `sections/*.md` - section files for navigation, targeted follow-up, and review.

Current default generation excludes *The Domestic*, the full Chapter 8 scenario, Appendix A pregenerated investigators, Appendix C bibliography, Appendix D maps/handouts, the index, character sheet facsimiles, contributor biographies, and back-cover material.

## Source-to-Output Strategy

- Use `rules-summaries` only after drafting from primary chapters, as a checklist for missing mechanics.
- Draft base rules before optional rules.
- Draft spell and skill catalogs from normalized templates, not source paragraph order.
- Draft scenario files by operational use: Folly operations, police process, London gazetteer, NPC/beings, case design, case seeds.
- Keep raw source in `private/`; only paraphrased outputs belong in tracked numbered rules files and `scenario/`.
