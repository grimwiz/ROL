# Advanced Mutation Map

Ledger of how `rules-advanced-source/12-advanced-options.md` is applied onto the
base corpus to produce `rules-advanced/`. Source pages are the rulebook's
printed pages (PDF index = printed page + 1).

Classification:

- **supersede** — replaces a base procedure; base text edited in place.
- **supplement** — extends/alters a base procedure for specific cases; added as
  a labelled subsection.
- **add** — new advanced topic; no base equivalent.
