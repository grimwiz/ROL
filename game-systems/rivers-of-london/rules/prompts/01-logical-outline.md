# Prompt: Logical Outline

Use after `00-source-inventory.md`.

Task:

Produce the target table of contents for the extracted corpus.

Requirements:

- Optimize for experienced roleplayers learning the system efficiently.
- Put prerequisites before dependent rules.
- Separate base rules, optional rules, and scenario-facing setting/process material.
- Do not mirror the rulebook's paragraph or chapter order unless that order is also the clearest final order.
- Keep file boundaries small enough that later completeness review can compare one file against the source.

Output:

- Final numbered rules file list with section headings.
- Final `scenario/` file list with section headings.
- Cross-reference list for rules that depend on other files.
- Subjects intentionally omitted, with reasons.
