# Prompt: Rules Draft

Use for one target rules file at a time.

Task:

Draft the requested rules file from the raw source and current outline.

Requirements:

- Rewrite in compact original wording.
- Preserve every mechanical detail, number, threshold, prerequisite, restriction, and exception.
- Use tables where they improve scan speed.
- Remove teaching examples, conversational text, flavour, fiction, and duplicated explanations unless needed to define a rule edge case.
- State whether rules are base, optional, advanced, or GM-facing.
- Add short internal source notes as HTML comments only where useful for later review.

Output:

- A complete Markdown draft for the named target file.
- A short checklist of source subjects covered.
- A short checklist of source subjects still needing PDF/parse verification.
