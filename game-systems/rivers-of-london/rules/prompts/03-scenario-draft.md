# Prompt: Scenario Draft

Use for one target scenario file at a time.

Task:

Draft the requested scenario reference file from the raw source and current outline.

Requirements:

- Rewrite in compact original wording.
- Keep only material useful for running or writing cases.
- Preserve operational facts, names, relationships, procedures, constraints, and case-hook logic.
- Avoid copying setting prose, jokes, fiction, long NPC descriptions, or boxed narration.
- Keep spoilers and GM-only information clearly labelled when relevant.

Output:

- A complete Markdown draft for the named target file.
- A source coverage checklist.
- A list of uncertain or table/map-dependent items needing PDF review.
