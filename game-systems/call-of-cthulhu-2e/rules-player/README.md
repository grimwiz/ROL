# Call of Cthulhu — Player Rulebook

The spoiler-free player edition. Everything an investigator needs to create a character and play, without revealing the Mythos.

| File | Covers |
|---|---|
| `00-system-overview.md` | What the game is, dice, the basic roll, Idea/Luck/Know, success levels. |
| `01-characteristics.md` | The nine characteristics, derived attributes, Damage Bonus Table. |
| `02-core-resolution.md` | d100 roll-under, special/impale, the Resistance Table, costs of failure. |
| `03-character-creation.md` | Procedure, occupations, skill points, the occupation table. |
| `04-skills.md` | Skill base-chance table, experience, skill notes. |
| `05-combat.md` | Rounds and DEX order, attack/parry/dodge, impale, melee & firearms tables. |
| `06-damage-and-healing.md` | Hit points, shock, healing, falling, drowning, poison. |
| `07-sanity.md` | The Sanity system: rolls, insanity, phobias, recovery. |
| `08-magic-and-mythos.md` | Player-facing magic mechanics — Cthulhu Mythos skill, Magic Points, casting, Increasing POW. |
| `09-beasts-and-creatures.md` | Generic non-Mythos creatures — animals, ghosts, wraiths, the undead. |
| `10-equipment-and-the-1920s.md` | The 1920s setting, money, prices, equipment, transport. |
| `11-the-1920s-reference.md` | Historical reference: strange-phenomena timeline, economy, travel, distances. |

Withheld from this edition (the Keeper reveals them in play): the Mythos bestiary, the Mythos/deity catalog, the full spell and tome lists, and Keeper procedures — all in `../rules-gm/`.
