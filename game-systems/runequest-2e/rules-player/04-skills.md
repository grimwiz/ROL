# Skills

<!-- Source: rulebook ch.VI (other skills) + appendix D p126 (combined/alchemist skills tables). Status: extracted-draft. -->

Non-combat skills are rated as percentages and resolved on `D100` (`02-core-resolution.md`). Each belongs to a **category** whose characteristic modifier (`01-characteristics.md`) is added to the listed **base chance** to set the starting "natural" ability; training and experience raise it from there. Skills are taught by **associations** (guilds and brotherhoods — `05-advancement.md`).

## Alchemist Skills

Alchemists make potions; each skill is rated and improved like any other, but its products are sold or used per the cost table.

| Skill | Training cost | Ingredient / dose | Potion cost |
|---|---|---|---|
| Acid Making | 500 L / potency level | 5 L / potency point | 50 L / potency point |
| Antidotes | as the agent countered | as the agent | as the agent |
| Blade Venom | 1000 L / potency level | 10 L / potency point | 100 L / potency point |
| Systemic Poison | 400 L / potency level | 4 L / potency point | 40 L / potency point |
| Battle Magic (potion) | 2000 L / spell point | 20 L / spell point | 200 L / spell point |
| Healing (potion) | 2000 L / HP healed | 20 L / HP healed | 200 L / HP healed |
| Power Restoring | 2000 L / POW point | 20 L / POW point | maker's use only |

Potions have a 10% chance of spoiling if unused for two years, and another 10% each two years after. Poisons and antidotes lose 10% potency every two years.

## Improving Skills

A skill is raised by **experience checks** after successful use, or by paid **training** from the appropriate association — see `05-advancement.md`, which lists the per-skill training costs by ability band.
