# Quick Reference

The at-the-table tables, gathered. Full rules are in the numbered files cited.

## Resolution (`02`)

- Roll `D100 ≤` ability. **01–05** always succeeds, **96–00** always fails. Base chance 5%.
- **Critical** ≤ ability ÷ 20 (ignores armour). **Impale/special** ≤ ability ÷ 5 (thrusting/missile: adds the weapon's max damage). **Fumble** → Fumble Table (`06`).
- **Experience check:** target = `(100 − ability) ± 3% per INT over 12 / under 9`; success = +5%.

## Resistance Table (`02`)

`chance % = 50 + 5 × (active − passive)`, roll that or less on `D100`. 50% when equal; clamps to 05–95%.

## Damage Bonus / Hit Points / Category Modifiers (`01`)

- **Damage bonus** by avg(STR,SIZ): 01-06 −1D4 · 07-12 none · 13-16 +1D4 · 17-20 +1D6 · each +8 +1D6.
- **Hit Points** = CON, ±SIZ/POW (see `01`).
- **Category modifiers** (Attack/Parry/Defense/Perception/Stealth/Manipulation/Knowledge/Oratory) — full table in `01`.

## POW Gain (`02`)

After overcoming a foe's magic resistance in real stress: roll `(20 − POW) × 5` or less on `D100`; then `01-10` → +3, `11-40` → +2, `41-00` → +1 POW.

## Divine Intervention (`10`)

Once per week, roll **current POW or less on `D100`** to make the god act. Rolling exactly your POW → the effect occurs but your soul is taken. POW lost (permanent, regainable) by the result:

|---|---|---|---|---|

| 06-10 | 1 | | 61-70 | 7 |
| 11-20 | 2 | | 71-80 | 8 |
| 21-30 | 3 | | 81-90 | 9 |
| 31-40 | 4 | | 91-95 | 10 |
| 41-50 | 5 | | 96-00 | no effect / no loss |

(The appendix table gives banded POW costs as above; the ch. VII example text states it more simply as "lose POW equal to the roll" — a minor source inconsistency.)
