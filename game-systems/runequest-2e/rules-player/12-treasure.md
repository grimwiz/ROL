# Treasure

<!-- Source: rulebook ch.IX p92-97 (treasure factors, treasure hoards, special items). Status: extracted-draft. The treasure-factor system (core mechanic) is given; the result tables (coins/gems/magic by factor) on p93-97 are to transcribe at the gate. -->

A monster hoard should reflect the danger of its guardians. The rulebook builds hoards from a **treasure factor** for each guardian, then rolls results on tables keyed to the total.

## Treasure Factor

A monster earns **1 treasure factor** for each of the following (round fractions up):

1. Each **5 Hit Points** (or fraction).
2. Each **25% chance to hit** (or portion — 30% = 2).
3. Each **extra die of damage** done (`+1D4` or `+1D6` count as 1).
4. Each **point of armour** protecting the whole body (3-point skin = 3).
5. Each **combat spell** possessed.
6. Each **special power** (e.g. a jack o'bear's mind control).
7. Each **5 levels of poison potency** used (a level-7 blade venom = 2).
8. Each **extra attack** (two claws = +1).

Sum the factors for every guardian; the combined total drives the hoard's size and contents. Each creature also has a listed **minimum** treasure factor in its bestiary entry (`11-monsters.md`), which extra abilities raise.

## Currency

- **Clack** — copper. **Lunar (L)** — silver, the standard unit. **Wheel** — gold; **1 Wheel = 20 L**.

## Hoard Contents

The total treasure factor sets how much is rolled. For each currency, roll `D100` (success by the factor) and multiply by a factor-scaled amount — e.g. Clacks `D100 × 20`, Wheels `D100 × 2`. Then roll `D100` for the **number of gem/jewellery items**, and roll each on the table below.

| D100 | Result | Worth |
|---|---|---|
| 01 | Special Jewellery | roll again here for worth + Special Item Table for type |
| 02 | Magical Crystal | Magic Crystal Table |

| 06-10 | Superb Gemstone | `1D10×1000` L |
| 11-15 | Excellent Jewellery | `1D6×1000` L |
| 16-20 | Excellent Gemstone | `3D6×100` L |
| 21-30 | Very Good Jewellery | `12D100` L |
| 31-40 | Very Good Gemstone | `6D100` L |
| 41-50 | Good Jewellery | `10D20` L |
| 51-60 | Good Gemstone | `2D100` L |

A **Special Item** result leads to magic: enchanted weapons/armour, **magic crystals** (POW storage, spell matrices, special powers), bound spirits, and potions. (The exact coin-amount-by-factor table and the Special Item / Magic Crystal tables on p94–97 are to transcribe at the gate.)
